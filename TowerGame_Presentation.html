01 / PROJECT OVERVIEW

프로젝트 개요

CONCEPT

영화 트론: 레거시의 사이버펑크 네온 비주얼을 배경으로, 플레이어는 FPS 전투와 실시간 타워 디펜스 건설을 동시에 수행합니다. Sanctum 2를 핵심 레퍼런스로 하여 전략과 액션을 융합한 하이브리드 경험을 제공합니다.

CORE LOOP
  • 실시간 통합: 전투와 건설이 중단 없이 동시 진행
  • FPS 전투: 직접 적을 공격하며 전선 유지
  • 즉시 건설: 전투 중 언제든 벽·타워 배치 가능
  • 보스 레이드: 다단계 패턴의 거대 보스 격파
  • 자원 순환: 적 처치 → 에너지 코어 획득 → 즉시 건설
  • 승리 조건: 최종 보스(Sentinel) 처치 시 클리어
KEY FEATURES
  • 실시간 모드 전환 (전투 ↔ 건설)
  • 그리드 기반 동적 경로 검증 시스템
  • 3종 무기 × 3종 타워 × 5종 적 캐릭터
  • 3페이즈 보스 전투 (Sentinel Boss)
REFERENCES
SANCTUM 2

FPS + Tower Defense 장르의 원형. 전투 중 건설의 실시간 통합 구조를 발전시켜 참조.

TRON: LEGACY

다크 배경의 네온 그리드, 글로우 이펙트, 사이버네틱 비주얼 스타일 전반 참조.

03 / MODE SYSTEM

모드 전환 시스템

⚔️ COMBAT MODE
  • 기본 FPS 조작 활성화
  • 3종 무기 사용: Single Shot · Shotgun · Repeater
  • 하이퍼 FPS 스타일 기동성 (회피 시스템)
  • 회피 횟수 제한 + 쿨타임 존재
  • Slow 디버프 저항 시스템 포함
  • 무기 수납 애니메이션으로 상태 표시
🏗️ CONSTRUCTION MODE
  • 그리드 바닥 타일과 상호작용 → 즉시 벽 배치 (실시간)
  • 기존 벽과 상호작용 → HUD 하단에 타워 건설 UI 표시
  • 기존 타워와 상호작용 → 타워 위 Floating UI 표시
  • 게임 흐름 중단 없이 모든 건설 즉시 처리
  • 경로 차단 불가 (알고리즘 자동 제한)
  • 에너지 코어 소모로 건설 비용 지불
🔄 MODE TRANSITION
  • 특정 키 입력으로 즉시 전환 (게임 중단 없음)
  • HUD 레이아웃 자동 변경으로 현재 모드 인지
  • 두 모드 모두 실시간 플레이 상태 유지
COMBAT MODE ⇌ CONSTRUCTION MODE 언제든 자유 전환 가능
04 / CONSTRUCTION SYSTEM

건설 시스템

STEP 1 · 벽 배치
🧱
  • 그리드 바닥 타일 클릭
  • UI 없이 실시간 즉시 배치
  • 경로 차단 시 배치 불가
  • 경로는 스폰→코어 최소 1개 유지 필수
STEP 2 · 타워 건설
🗼
  • 설치된 벽과 상호작용
  • HUD 하단에 타워 건설 UI 실시간 표시
  • 게임 흐름 중단 없이 즉시 선택·설치
  • 에너지 코어 소모
  • 3종 타워 중 선택하여 설치
STEP 3 · 타워 업그레이드
⬆️
  • 설치된 타워와 상호작용
  • 타워 위에 Floating UI 실시간 표시
  • 게임 흐름 중단 없이 즉시 업그레이드
  • 성능 강화: 공격력, 사거리 등
  • 특수 기능 추가 가능
GRID SYSTEM
  • 월드 좌표 ↔ 그리드 인덱스 자동 변환 (TGGridBase)
  • 셀 상태: Empty / Wall / Tower / Entry / Exit
  • 실시간 경로 검증으로 막힌 배치 차단
ECONOMY SYSTEM
  • 적 처치 시 에너지 코어 자동 흡수
  • 벽/타워 건설에 에너지 코어 소모
  • 총 설치 개수 및 밀집도 제한으로 무분별 건설 방지

08 / BOSS RAID

보스 전투 — Sentinel

👾 SENTINEL BOSS
  • 모든 웨이브 클리어 후 등장하는 거대 보스
  • 3단계 페이즈 구조로 난이도 단계적 상승
  • 광범위 공격 패턴 — 회피가 핵심
  • 3단계 페이즈 전환으로 패턴 변화
  • 보스전 중에도 타워 재건설 가능
BOSS PHASES
1
PHASE 1 — 기본 공격
지면 실린더 범위 공격 패턴 활성화
2
PHASE 2 — 강화 패턴
구형 범위 광역 공격 추가, 이동속도 증가
3
PHASE 3 — 분노 상태
공격 빈도·속도 증가, 최고 난이도
ATTACK PATTERNS
  • 지면 실린더 공격: 원통형 범위로 플레이어 타격 (TGGroundCylinderPattern)
  • 구형 범위 공격: 구 형태의 폭발 범위 (TGSphereAreaPattern)
  • 패턴 기본 클래스 상속으로 확장 용이 (ATGPatternBase)
STRATEGY TIPS
  • 보스 진입 전 타워 최대 강화 권장
  • Slow Tower로 보스 이동·공격 속도 감소
  • Buff Tower로 전투 중 플레이어 체력 유지
  • Attack Tower + Slow Tower 조합으로 딜 효율 극대화
